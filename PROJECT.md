# Project

You are tasked with creating an open-source, multilingual (English & Spanish), AI-enabled, Offline-first, multi-device-syncable, Macro & Calorie Tracker, that is a PWA with a beautiful modern UI, called OpenMacros


There should be an onboarding process, that allows the user to input all the applicable information about themselves.

There should be an extensive library of foods and meals, with many pre-existing foods and meals, and a way to add more of both.

There should be a way to track any meals and snacks consumed through the day, along with the calories and macros of each.

The user should have a simple way to type in everything that's needed, OR, they should be able to take a picture of the meal, and have it fed to an AI through OpenRouter (defaulting to the 'z-ai/glm-4.6v:floor' model), with a useful prompt to get all the applicable macros, calories, title, and description from the image.

In the user settings, the user should be able to add an OpenRouter API Key, and select (or type in) which other models they might want to use. They should also be able to add a `:[tag]`, (such as `:floor`, `:nitro`).

The user should be able to sync their accounts and data between devices, without requiring a login.

The user should be able to open a new instance of the app, and scan a QR code in an existing version, and have the data sync live between the two instances into the future.

Expect that the existing library of food/meals will develop over time (so, should be able to auto-update as time goes on).

The app should be optimized to minimize the amount of typing required to successfully use the app.
